HR Analytics – Interactive Department-Level Dashboard

Project Overview

This project is an interactive HR Analytics dashboard built using Microsoft Excel to explore and visualize workforce data across different departments.

The dashboard brings together key HR metrics in one place, making it easier to understand employee demographics, workforce distribution, compensation, training participation, and performance trends.

The goal of this project was to practice using Excel to transform employee data into meaningful visual insights that can support HR reporting and workforce decision-making.

Dashboard Preview



Key HR Metrics

The dashboard provides an overview of the following workforce indicators:

Total Employees: Overall employee headcount.

Average Tenure: Average length of employee service.

Average Age: Average age across the workforce.

Average Salary: Overall average employee salary.

Average Training Hours: Average training hours completed.

Average Performance Rating: Overall employee performance rating.

Dashboard Features

The dashboard includes interactive filters (slicers) that allow users to explore workforce data based on:

Employment Type (Full-Time and Part-Time)

Gender

Location

Ethnicity

It also includes the following visualizations:

Active Employees by Department: Displays employee distribution across departments.

Employees by Location: Compares department-level employee distribution across different locations.

Average Salaries by Department: Highlights salary differences across departments.

Average Performance Rating by Department: Compares average employee performance ratings.

Average Training Hours by Department: Examines training participation across departments.
